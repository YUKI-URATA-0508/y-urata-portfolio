## 1440px幅の比較

カンプは1024 × 1536px。1440px幅へ等比換算すると全体高2160pxです。初回実装は2192pxでしたが、About画像の位置、見出し下の余白、カードの高さ、ContactとFooterのパディングを調整し、最終実装の全体高は2161pxになりました。

| セクション | 開始位置 | 高さ |
| --- | ---: | ---: |
| Hero | 0px | 590px |
| About | 590px | 419px |
| Works | 1009px | 534px |
| Skills | 1543px | 307px |
| Contact | 1850px | 256px |
| Footer | 2106px | 55px |

値はChromiumの`getBoundingClientRect()`の計測結果を四捨五入しています。コンテンツ幅は1440px時に約1240px、本文の左端は約115pxを基準としています。

## カンプと完全一致していない箇所

- 写真6点は独立したUnsplash仮写真です。Heroの建物、Aboutの机・モニター、実績画像、Contactの人物と山岳の構図は一致していません。とくにHeroの背景は見た目への影響が大きいため、正式素材への差し替えを推奨します。
- 元フォント情報がないため、Inter / Noto Sans JPを使用しています。字幅・ウェイト・字形・細かい行間は完全一致ではありません。
- ラインアイコン・SNSアイコンはSVGで近似しています。
- フッターの年はビルド時の年（2026）です。カンプの2024とは異なります。
- セクションの境界位置や細かい罫線・余白は画像からの目視換算です。全体の高さが近いことは、すべての要素のピクセル一致を保証するものではありません。
- モバイルカンプがないため390pxは基本的な積み重ね配置です。モバイル専用デザインの再現を検証したものではありません。
